Intelligent Diabetic Retinopathy Grading and Quality Assurance System

An AI-based system for Diabetic Retinopathy (DR) grading from retinal fundus images, with an additional image quality assessment stage to identify images that are not suitable for reliable diagnosis.

The system aims to provide an automated and explainable prediction using Deep Learning and Explainable AI (XAI) techniques.

Project Overview

Diabetic Retinopathy is a diabetes-related eye disease that can lead to vision loss if not detected and managed early.

This project develops an automated pipeline that:

Checks the quality of the input retinal image.
Rejects ungradable or low-quality images.
Classifies gradable images into one of five Diabetic Retinopathy grades.
Provides the model's prediction confidence.
Uses Grad-CAM to highlight image regions that contributed to the prediction.
