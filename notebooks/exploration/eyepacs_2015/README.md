# EyePACS 2015 notebooks

Audit, validation and quality analysis of the EyePACS 2015 Kaggle mirror (`sovitrath/diabetic-retinopathy-2015-data-colored-resized`). Run in order `01` → `02` → `03`. Overview of all exploration notebooks: [`../README.md`](../README.md).

In model v2, EyePACS images enter training through the Kaggle job `kaggle/kernels/rg_eyepacs_data.py` (hi-res mirror, patient-level split). The quality analysis in `03` is the starting point for the image-quality gate.
